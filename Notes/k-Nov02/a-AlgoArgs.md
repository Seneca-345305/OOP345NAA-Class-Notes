| Argument | What it tells the algorithm | Example |
|---|---|---|
| Input range | Where to begin and where to stop | Count between `marks.begin()` and `marks.end()` |
| Value | What to find, count, or assign | Count occurrences of `60` |
| Callable | What condition or operation to apply | Count marks for which `mark >= 50` is true |
| Destination iterator | Where to write results | Copy into an existing destination range |
| Another input or initial value | Additional data needed by the task | Add corresponding elements, or start a total at `0.0` |
